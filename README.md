# Geospatial File Measurement API

Upload a Shapefile or KML file and get accurate areas and lengths for every feature — computed in
the right map projection, never in raw latitude/longitude degrees.

This repository holds the backend service ([`backend/`](backend/)) and, soon, a web interface
(`frontend/`). Full documentation is coming; the backend's technical documentation is in
[`backend/README.md`](backend/README.md).
